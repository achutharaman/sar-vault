# Code of Conduct

## Our standard

Be respectful and constructive. Focus on the work, not the person. Technical
criticism is welcome and expected — this is a security project, and challenging
design decisions is the point. Personal attacks, harassment, and bad-faith
participation are not.

## Unacceptable behaviour

- Harassment, insults, or discriminatory remarks
- Publishing others' private information
- Deliberately submitting insecure or malicious code, or misrepresenting a change's
  security impact
- Publicly disclosing a vulnerability before the process in SECURITY.md has run

## Enforcement

Report issues to the maintainer via the email on their GitHub profile. Reports are
handled confidentially. The maintainer may remove comments, close contributions, or
block accounts that violate this document.
